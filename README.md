# Superme Super No1 Game

Offline-first open-world 3D game prototype for Android.

## Current prototype
- Procedural 3D city and roads
- Third-person player movement
- Enter/exit and drive prototype vehicles
- Reactive NPC prototype with different personalities
- Day/night clock
- Offline-first architecture
- Starter HUD

## Planned systems
Cars and motorcycles, customization, economy and 300+ activities, police/emergency services, phone, jobs, homes/garages, weapons and fictional sci-fi weapons, advanced NPC AI, Uzbek/multilingual voice, and optional online multiplayer.

The prototype uses original placeholder geometry. Real-world vehicle brands/models and other licensed IP require appropriate rights before commercial distribution.

## Engine
Godot 4.x. Android export is supported by Godot; the project should be kept mobile-conscious as the world grows.
